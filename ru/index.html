Начать с агентом

Вставьте это в Claude Code или Codex. Агент установит gestor и проведёт первую сессию, по одному вопросу за раз. Он ничего не подаёт, не подписывает и не оплачивает.

Для Claude Code или Codex

Установи gestor из https://github.com/gestor-es/gestor-es и проведи мою первую сессию. Говори со мной по-русски.

1. Склонируй в ~/gestor-es. gestor нужен Python 3.12+: если python3 старее, помоги поставить новый и используй его ниже.

2. В ~/gestor-es запусти интерфейс так, чтобы он работал и после твоего выхода:

nohup python3 -m gestor > gestor.log 2>&1 &

Потом дай мне ссылку http://127.0.0.1:8765.

3. Подключи MCP-сервер gestor для своей программы командой из раздела README «Помощь в Sede из Claude Code или Codex», запуская из ~/gestor-es.

4. Скажи мне перезапустить тебя в ~/gestor-es, чтобы сервер загрузился (`claude --continue` или `codex resume --last`), и написать «продолжай». Потом следуй инструкциям First session от сервера gestor.

Ничего не подавай, не подписывай и не оплачивай. Не спрашивай PIN Cl@ve, пароли и пароль сертификата.

Следующие сессии: в Claude Code — /mcp__gestor__start, в Codex — «начни с gestor». Агент назовёт ближайший срок и что для него нужно.

Как работает

01local

Работает на вашем компьютере. Python 3.12+, только стандартная библиотека, один файл SQLite на профиль в ~/.gestor.

02§

У каждой суммы есть знак §. Он открывает источник: цитату из BOE, AEAT или DGT на испанском, перевод и что это значит для вас.

03MCP

MCP-сервер даёт Claude Code или Codex читать ваши книги и декларации. Черновики он сохраняет только после вашего явного «да».

04Validar

В Sede AEAT агент открывает форму, загружает файл или вводит casillas и нажимает «Validar». «Presentar» он не нажимает. Подписываете вы.

05EN · ES · RU

Интерфейс, источники права, база знаний и документация на английском, испанском и русском.

Посмотрите на вымышленном профиле: из чего состоит gestor, путь одного счёта и разобранный квартал. Как работает gestor

Вопросы

gestor подаёт декларации за меня?
Нет. gestor считает декларации и готовит файл для импорта в Sede AEAT. Вы проверяете цифры и подписываете в Sede сами.
Где хранятся мои данные?
На вашем компьютере, в одном файле SQLite на профиль в ~/.gestor.
Для кого gestor?
Для autónomo в Испании на общем IRPF или в режиме Beckham и для Sociedad Limitada с одним участником и доходом от услуг.
С какими ИИ-агентами работает gestor?
С Claude Code и Codex, через MCP-сервер gestor. Агент читает ваши книги и декларации, сохраняет черновики после вашего явного «да» и может заполнить форму в Sede AEAT в вашем браузере.
Можно ли пользоваться gestor без ИИ-агента?
Да. Склонируйте репозиторий и запустите python3 -m gestor. Интерфейс откроется по адресу http://127.0.0.1:8765.
gestor заменяет gestoría?
Нет. Он считает и объясняет декларации autónomo или SL с одним участником, а подаёте их вы. Каждый источник права помечен: прямо в тексте, толкование или спорно. По спорным вопросам и для полной бухгалтерии SL обращайтесь к специалисту.
Это налоговая консультация?
Нет. gestor считает и объясняет с источниками из BOE, AEAT и TGSS. Проверяйте каждую цифру до подписи.
Сколько стоит gestor?
Нисколько. Это открытый код под лицензией MIT.
