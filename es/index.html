Empiece con su agente

Pegue esto en Claude Code o Codex. El agente instala gestor y le guía en la primera sesión, una pregunta cada vez. Nunca presenta, firma ni paga.

Para Claude Code o Codex

Instala gestor desde https://github.com/gestor-es/gestor-es y guíame en la primera sesión. Háblame en español.

1. Clónalo en ~/gestor-es. gestor necesita Python 3.12+: si python3 es más antiguo, ayúdame a instalar uno nuevo y úsalo abajo.

2. En ~/gestor-es arranca la interfaz para que siga funcionando cuando salgas:

nohup python3 -m gestor > gestor.log 2>&1 &

Luego dame el enlace http://127.0.0.1:8765.

3. Conecta el servidor MCP de gestor para tu programa con el comando de la sección del README «Ayuda en la Sede desde Claude Code o Codex», ejecutado desde ~/gestor-es.

4. Dime que te reinicie en ~/gestor-es para que se cargue el servidor (`claude --continue` o `codex resume --last`) y que escriba «continúa». Después sigue las instrucciones First session del servidor gestor.

No presentes, firmes ni pagues nada. No me pidas el PIN de Cl@ve, contraseñas ni la clave del certificado.

Sesiones siguientes: en Claude Code escriba /mcp__gestor__start; en Codex escriba «empieza con gestor». El agente indica el plazo más cercano y qué hace falta para él.

Cómo funciona

01local

Funciona en su ordenador. Python 3.12+, solo la biblioteca estándar, un fichero SQLite por perfil en ~/.gestor.

02§

Cada importe lleva una marca § que abre su fuente: la cita literal del BOE, la AEAT o la DGT y qué significa para usted.

03MCP

Un servidor MCP permite a Claude Code o Codex leer sus libros y declaraciones. Solo guarda borradores después de su «sí» explícito.

04Validar

En la Sede de la AEAT el agente abre el formulario, importa el fichero o escribe las casillas y pulsa «Validar». No pulsa «Presentar». Firma usted.

Preguntas

¿gestor presenta mis declaraciones?
No. gestor calcula las declaraciones y prepara un fichero para importar en la Sede de la AEAT. Usted revisa las cifras y firma en la Sede.
¿Dónde se guardan mis datos?
En su ordenador, en un fichero SQLite por perfil en ~/.gestor.
¿Para quién es gestor?
Para un autónomo en España en IRPF general o en régimen Beckham, y para una Sociedad Limitada de un solo socio con ingresos por servicios.
¿Qué agentes de IA funcionan con gestor?
Claude Code y Codex, a través del servidor MCP de gestor. El agente lee sus libros y declaraciones, guarda borradores después de su «sí» explícito y puede rellenar el formulario de la Sede de la AEAT en su navegador.
¿Puedo usar gestor sin un agente de IA?
Sí. Clone el repositorio y ejecute python3 -m gestor. La interfaz se abre en http://127.0.0.1:8765.
¿gestor sustituye a una gestoría?
No. Calcula y explica las declaraciones de un autónomo o de una SL de un solo socio, y usted las presenta. Cada fuente jurídica está marcada como explícita en el texto, interpretación o discutida. Para los puntos discutidos y la contabilidad completa de una SL, consulte a un profesional.
¿gestor es asesoramiento fiscal?
No. Calcula y explica con fuentes del BOE, la AEAT y la TGSS. Compruebe cada cifra antes de firmar.
¿Cuánto cuesta gestor?
Nada. Es de código abierto con licencia MIT.
