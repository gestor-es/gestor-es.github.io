For Claude Code or Codex

Install gestor from https://github.com/gestor-es/gestor-es and guide my first session. Talk to me in my language.

1. Clone it into ~/gestor-es. gestor needs Python 3.12+: if python3 is older, help me install a newer one and use it below.

2. In ~/gestor-es start the interface so it keeps running after you exit:

nohup python3 -m gestor > gestor.log 2>&1 &

Then give me the link http://127.0.0.1:8765.

3. Connect the gestor MCP server for your program with the command from the README section "Help in the Sede from Claude Code or Codex", run from ~/gestor-es.

4. Tell me to restart you in ~/gestor-es so the server loads (`claude --continue` or `codex resume --last`) and to write "continue". Then follow the gestor server's First session instructions.

Never file, sign or pay anything. Never ask for my Cl@ve PIN, passwords or certificate passphrase.

Later sessions: in Claude Code type /mcp__gestor__start; in Codex write “start gestor”. The agent names the nearest deadline and what it needs.

How it works

01local

Runs on your computer. Python 3.12+, standard library only, one SQLite file per profile in ~/.gestor.

02§

Every amount has a § mark that opens its source: the Spanish quote from BOE, AEAT or DGT, a translation and what it means for you.

03MCP

An MCP server lets Claude Code or Codex read your books and returns. It writes drafts only after your explicit “yes”.

04Validar

In the AEAT Sede the agent opens the form, imports the file or types the casillas and presses “Validar”. It does not press “Presentar”. You sign.

05EN · ES · RU

Interface, legal sources, knowledge base and docs in English, Spanish and Russian.

Not covered yetBank import, full SL bookkeeping (journal, annual accounts), Verifactu. The Sede import files are not yet validated on the real Sede.

Questions

Does gestor file my tax returns?
No. gestor computes the returns and prepares a file for the AEAT Sede import. You check the figures and sign in the Sede yourself.
Where is my data stored?
On your computer, in one SQLite file per profile in ~/.gestor.
Who is gestor for?
An autónomo in Spain under the general IRPF or the Beckham regime, and a one-person Sociedad Limitada with service income.
Which AI agents work with gestor?
Claude Code and Codex, through the gestor MCP server.
Is gestor tax advice?
No. It calculates and explains with sources from BOE, AEAT and TGSS. Check every figure before you sign.
How much does gestor cost?
Nothing. It is open source under the MIT license.
