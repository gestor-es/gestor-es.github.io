gestor: how it works now

01One idea

gestor stores only facts. Each time, it recalculates all the returns from them. You file the returns.

INPUTFactsInvoices, expenses, profile and filed returns. You enter them in forms.
INSIDECalculationThe engine calculates the casillas each time a page opens. It does not store amounts that it has already calculated.
OUTPUTYou filegestor gives you the casillas, the rule with § and the file for the Sede. You sign on the Sede.

    07How the agent helps with the Sede

    “Presentar declaración” or “Firmar y enviar”. This rule is written in INSTRUCTIONS. You sign.

    08What gestor does not do

    • It does not file returns and does not pay.
    • It does not read the bank. You or the agent enter the statement.
    • It does not calculate the surcharges for late returns.
    • Casilla 72 of modelo 303 appears only in a note.
    • It only knows national public holidays. If a deadline falls on a weekend or a national holiday (Good Friday too), gestor moves it to the next working day. It does not take regional or local holidays into account, although they also extend the deadline.
    • The files for “Importar” have not yet been tested on the real Sede. In the 151 file, the fields for sex, date of birth and IAE matched the reference file of another program byte for byte.
